# Ethics

OPSEC Mirror is framed as a defensive assessment tool.

## Intended Use

- exposure assessment
- training
- mitigation planning
- red-team style defensive rehearsal

## Excluded Use

- targeting
- harassment
- operational harm
- facilitating violence

## Engineering Safeguards In This Scaffold

- defensive-use warning in the UI and API contract
- interface-first collectors for sensitive sources
- demo caches kept separate from live collection mode
- no undocumented Danti dependency
